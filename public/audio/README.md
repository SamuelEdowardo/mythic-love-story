# Audio Assets Guide

Tempatkan file audio MP3 Anda di folder ini:

1. `intro.mp3`: Musik latar saat petualangan/gaming (Chapter 0 sampai Chapter 6)
2. `romantic.mp3`: Musik latar romantis yang mulai berputar saat melangkah masuk ke Final Portal (Chapter 7 sampai Ending)

Opsional untuk SFX di folder `sfx/`:
- `click.mp3`
- `flip.mp3`
- `match.mp3`
- `celebrate.mp3`
